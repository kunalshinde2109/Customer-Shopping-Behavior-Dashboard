# 🛍️ Customer Shopping Behavior Analytics Dashboard

An interactive data analytics dashboard built using Python and Streamlit to explore customer shopping behavior, purchasing patterns, sales trends, and customer insights.

## 📸 Dashboard Preview

![Customer Shopping Behavior Dashboard](screenshots/dashboard_home.png)

## 📊 Project Overview

This project analyzes customer shopping data to understand purchasing habits, customer preferences, product performance, and shopping trends through interactive visualizations.

## 🚀 Dashboard Features

- Home Dashboard
- Dataset Overview
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Executive Overview
- Shopping Behavior Analytics
- Purchase Explorer
- Shopping Insights
- Project Information

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Streamlit

## 📁 Dataset

The dataset contains 3,900 customer shopping records and 18 features related to purchasing behavior, including:

- Customer Age
- Gender
- Product Category
- Purchase Amount
- Season
- Payment Method
- Review Rating
- Subscription Status
- Shopping Frequency
- Discount & Promo Code Usage

## 📈 Key Objectives

- Analyze customer purchasing patterns
- Explore product and category performance
- Understand customer preferences
- Identify shopping trends
- Visualize insights through interactive charts

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run customer_dashboard.py
```
